# M. Hassnain Jafar Portfolio

A modern personal portfolio website for M. Hassnain Jafar, a BS Computer Science student and web developer learning modern web technologies.

## Features

- Responsive portfolio layout for desktop, tablet, and mobile
- Modern dark UI based on a Google Stitch frontend design
- Hero section with name, role, introduction, and call-to-action buttons
- Download CV button linked to a local PDF
- About and education section
- Skills section
- Featured projects section
- GitHub and LinkedIn links
- Contact section with email and phone links
- Mobile navigation menu

## Tech Stack

- HTML
- Tailwind CSS CDN
- JavaScript
- Google Fonts
- Material Symbols Icons

```powershell

```

Then open:

```text

```

To stop the server, press `Ctrl + C`.

## Deployment

This is a static website, so it can be deployed on:

- GitHub Pages
- Netlify
- Vercel
- Any static hosting service

For GitHub Pages:

1. Push the project files to a GitHub repository.
2. Open the repository settings.
3. Go to **Pages**.
4. Select the branch, usually `main`.
5. Save and wait for GitHub to publish the site.
